# 首页模型价格验真链接与移动端文字修复设计

## 目标

在客户主题首页的模型价格面板中增加“检查真伪”外链，并修复移动端模型名称因颜色继承导致对比度不足的问题。

## 范围

- 目标页面：`web/customer/src/pages/Home/index.tsx`
- 样式文件：`web/customer/src/styles.css`
- 国际化：`web/customer/src/i18n/locales/{en,zh,zh-TW,ru}.ts`
- 不改动默认主题、后台页面、定价数据和服务端接口。

## 交互与视觉

1. 在价格面板顶部的单位说明和“服务监控”之间增加“检查真伪”链接。
2. 链接使用盾牌确认图标，与“服务监控”保持相同的字号、颜色、间距和悬停反馈。
3. 链接指向 `https://www.hvoy.ai`，使用 `target="_blank"` 和 `rel="noreferrer"`。
4. 桌面端三个辅助信息项横向排列；移动端允许信息区换行，避免长语言文案溢出。
5. 模型名称显式使用页面主文字色，避免依赖表格单元格的继承颜色，确保白色背景下可见。

## 国际化

新增英文源键 `Check authenticity`：

- 简体中文：检查真伪
- 繁体中文：檢查真偽
- 英文：Check authenticity
- 俄文：Проверить подлинность

## 组件与数据流

该功能为静态外链，不新增状态、请求或业务数据。链接直接渲染在现有 `mp-panel-meta` 容器中，并复用现有图标库和翻译组件 `T`。

## 错误与安全处理

- 外站不可用时由浏览器展示标准网络错误，不影响价格面板本身。
- 新标签页使用 `noreferrer`，避免向外站暴露 opener 上下文。
- 使用原生 `<a>` 元素，保留键盘导航和浏览器默认链接语义。

## 验证

1. 运行客户主题 TypeScript 检查和生产构建。
2. 检查 320px、375px 和桌面宽度：链接不溢出，模型名称可读，价格表仍可横向滚动。
3. 使用键盘 Tab 确认两个外链均可聚焦。
4. 确认“检查真伪”在新标签页打开正确地址。
5. 确认现有“服务监控”链接和模型切换行为不受影响。
